# M1p11MEAN

Full-stack web application built with the MEAN stack and WebSocket for real-time communication.

## Tech Stack

* **Angular** — Frontend
* **Node.js / Express.js** — Backend & REST API
* **MongoDB** — Database
* **WebSocket** — Real-time communication

## Features

* Full-stack web application
* REST API
* Real-time communication with WebSocket
* MongoDB data persistence

## Getting Started

```bash
git clone https://github.com/Sarobid/m1p11mean.git
cd m1p11mean
```

Install dependencies and start the frontend and backend according to the project configuration.
